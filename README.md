# Weblign — Meta Ads Landing Page

A production-ready Next.js landing page for **go.weblign.in**. It is built for paid traffic: a hero enquiry form, WhatsApp fallback, Meta Pixel events, transparent pricing, and a static-prerendered SEO setup.

## Stack

- Next.js 16 (App Router, static prerender)
- React 19 + TypeScript
- Tailwind CSS 4
- Deployed on Vercel (recommended)

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

Other commands:

```bash
npm run build   # production build
npm run start   # run the production build
npm run lint    # ESLint
npm run brand   # regenerate logo, favicon and OG image assets
```

## Environment variables

Copy `.env.example` to `.env.local` and set the real values.

| Variable | Required | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | Recommended | WhatsApp number in international format, digits only (for example `919XXXXXXXXX`). Without it, WhatsApp buttons fall back to email. |
| `NEXT_PUBLIC_EMAIL` | Yes | Enquiry inbox. Defaults to `info.weblign@gmail.com`. |
| `NEXT_PUBLIC_META_PIXEL_ID` | For ads | Meta Pixel ID. The pixel is not loaded when empty — no fake IDs. |
| `NEXT_PUBLIC_LEAD_API_ENDPOINT` | Optional | POSTs form JSON here. When empty, the visitor gets a prefilled WhatsApp/email handoff so the lead is not lost. |
| `NEXT_PUBLIC_SITE_URL` | Yes | Canonical URL. Use `https://go.weblign.in`. |
| `NEXT_PUBLIC_MAIN_SITE_URL` | Yes | Main brand site, `https://weblign.in`. |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | Optional | Google Search Console HTML tag content value. |

Restart `npm run dev` after changing `.env.local`.

## Form and tracking

- Required fields: full name, WhatsApp/phone, service required.
- Optional fields: business name, budget, project description.
- With `NEXT_PUBLIC_LEAD_API_ENDPOINT` set, the form POSTs JSON and shows a success state.
- Without an endpoint, the form shows “One last step” with prefilled WhatsApp and email links.
- Meta Pixel events: `PageView` (automatic), `FormStart`, `Lead`, and `Contact` (WhatsApp clicks). Only loaded when a pixel ID is set.

## Deploy to Vercel

1. Push this folder to a Git repository.
2. In Vercel, choose **Add New → Project** and import the repository. The project name can be anything; the domain is configured separately.
3. Framework preset: **Next.js**. Build command `npm run build`, output is handled automatically.
4. Add the environment variables above for **Production** (and Preview if needed).
5. Deploy.
6. Open **Project → Settings → Domains → Add** and enter `go.weblign.in`.
7. At your DNS provider, add a **CNAME** record:
   - Name/Host: `go`
   - Value/Target: `cname.vercel-dns.com`
   - TTL: automatic or 3600
8. Wait for DNS verification in Vercel. HTTPS is issued automatically.

If `weblign.in` uses Vercel nameservers, you can add the subdomain directly in Vercel DNS instead of a CNAME.

After the domain is live, set `NEXT_PUBLIC_SITE_URL=https://go.weblign.in` in Vercel and redeploy so canonical URLs, Open Graph URLs, sitemap, and schema use the final domain.

## SEO setup

Already included:

- Canonical URL, `en-IN` locale, optimized title and description
- Open Graph and Twitter card image (`/og-image.png`, 1200×630)
- `robots.txt` and `sitemap.xml` generated by Next.js
- `manifest.webmanifest` and branded favicon/apple icon
- JSON-LD `@graph`: Organization/ProfessionalService, WebSite, WebPage, FAQPage, and service offers
- Security headers and clean semantic headings
- Static prerendering for fast indexing

After deployment:

1. Add the property in [Google Search Console](https://search.google.com/search-console) and verify it with the HTML tag value in `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`.
2. Submit `https://go.weblign.in/sitemap.xml`.
3. Validate structured data with the [Rich Results Test](https://search.google.com/test/rich-results) and [Schema Markup Validator](https://validator.schema.org/).
4. Test the share preview with the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and refresh the cache after changes.
5. Add the page to your Google Business Profile and relevant business listings.
6. Earn real backlinks and publish genuine project case studies over time. Avoid paid link schemes.

## Brand assets

`scripts/generate-brand-assets.mjs` is the single source for the logo mark and generated assets:

- `src/app/icon.svg`, `src/app/apple-icon.png`, `src/app/favicon.ico`
- `public/brand/logo-mark.svg`, `logo-mark-light.svg`, `logo-192.png`, `logo-512.png`
